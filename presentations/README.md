# Презентації 15 занять (Google Slides)

- `content.py` — зміст 15 лекцій (16 слайдів кожна), перевірений на довжину полів шаблону.
- `check.py` — перевірка, що тексти вміщуються в поля шаблону.
- `gen.py` — генератор запитів Google Slides API:
  - `python gen.py skel` — збирає каркас із 16 слайдів у КОПІЇ шаблону
    (шаблон: 1TrugM8TxXvtoJDmiN_ZJvyMbGooWJZHUlX91oVcv5EM; ID елементів g32a47ba9a3d_0_*);
  - `python gen.py N` — replaceAllText-запити для заняття N у копії каркаса.

Порядок: копія шаблону → skel → 15 копій каркаса в папку «Презентації»
(1CprX2BeEtz9s85Q6qNb5hoa67HmGIoxh) → gen.py N для кожної → перевірка рендеру →
посилання й статуси в таблиці r_d (аркуш «Підготовка контенту», колонки L/M).

## Версія v2 — розширений курс (2026-11-10)

Кожна з 15 презентацій перебудована з 16 до **29 слайдів** (ID `V01_pg` … `V29_pg`):

| Слайди | Блок |
|---|---|
| V01–V05 | обкладинка, лектор, план, результат, терміни заняття |
| V06–V12 | Частина 1 «Теорія»: два теоретичні блоки, схема процесу, 3 ідеї, код/таблиця, приклад на V01 |
| V13–V17 | Частина 2 «Демо»: 6 кроків, код демо з контрольним числом, типові помилки, контрольні точки |
| V18 | перерва |
| V19–V24 | Частина 3 «Практика»: 3 вправи з критерієм приймання, відповіді (V23), Base/Core/Challenge |
| V25–V29 | контрольні питання, відповіді, ДЗ, література, підсумок |

Кожен слайд має нотатки лектора з хвилинами сценарію 150 хв.

Файли:
- `content_v2.py` — новий зміст (терміни, вправи, відповіді, демо, нотатки); числа звірені зі staging V01 і Track B.
- `manual_notes.py` — блоки посібника викладача (C/E/I/J/K), що потрапляють у нотатки.
- `gen2.py` — `python3 gen2.py build N a|b` будує batchUpdate: `duplicateObject` слайдів S01–S16 як макетів
  (разом із полем нотаток), заміна тексту, потім видалення S01–S16 і `updateSlidesPosition`
  по одному слайду (масив із 29 ID одним запитом API відхиляє).
- `check2.py` — перевірка довжин текстів під поля шаблону.
- `update_docs.py` — додає розділи v2 у програму курсу («Теорія і практика заняття (слайди v2)»)
  і в посібник викладача (0.2 «Структура презентації v2» та «L. Слайди v2: теорія, вправи, відповіді»
  для кожного заняття). Скрипт ідемпотентний: перед вставкою прибирає попередні блоки v2.

Таблиця r_d, колонка M: статус «🟢 готово v2 …» для занять 1–15.
