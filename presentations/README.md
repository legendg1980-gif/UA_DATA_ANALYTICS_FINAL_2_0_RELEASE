# Презентації 15 занять (Google Slides)

- `content.py` — зміст 15 лекцій (16 слайдів кожна), перевірений на довжину полів шаблону.
- `check.py` — перевірка, що тексти вміщуються в поля шаблону.
- `gen.py` — генератор запитів Google Slides API:
  - `python gen.py skel` — збирає каркас із 16 слайдів у КОПІЇ шаблону
    (шаблон: 1TrugM8TxXvtoJDmiN_ZJvyMbGooWJZHUlX91oVcv5EM; ID елементів g32a47ba9a3d_0_*);
  - `python gen.py N` — replaceAllText-запити для заняття N у копії каркаса.

Порядок: копія шаблону → skel → 15 копій каркаса в папку «Презентації»
(1CprX2BeEtz9s85Q6qNb5hoa67HmGIoxh) → gen.py N для кожної → перевірка рендеру →
посилання й статуси в таблиці r_d (аркуш «Підготовка контенту», колонки L/M).
